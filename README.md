# Behavior-of-Pendulums

## Double Pendulum Simulation

A simple yet insightful physics simulation of a **double pendulum system**, demonstrating chaotic motion and nonlinear dynamics. This project is useful for educational purposes, physics demonstrations, or integration into larger simulation environments.

## 🧠 What is a Double Pendulum?

A double pendulum consists of one pendulum attached to the end of another. It exhibits complex and highly sensitive behavior due to its nonlinear equations of motion, making it a classic example of deterministic chaos.

---

## 🎯 Features

- Simulates the dynamics of a two-link pendulum using Lagrangian or Newtonian mechanics.
- Real-time animation of motion.
- Adjustable initial conditions (angles and angular velocities).
- Optional data logging or visualization using PyQt / OpenGL.
- Clear code structure for easy modification and experimentation.
